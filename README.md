# GeoModel3D — 掌上地质三维建模系统 (初赛 Demo)

## 项目简介

GeoModel3D 是一款基于 Web 的地质三维建模演示应用，使用 Three.js 实现 3D 渲染，支持在浏览器中直接体验地质数据的可视化和分析。

## 核心功能

### 1. 钻孔数据 3D 可视化
- 加载示例数据（9 个模拟钻孔）
- 导入 CSV 格式的钻孔数据
- 3D 场景中展示钻孔轨迹，岩性按分层自动着色
- 鼠标左键旋转、右键平移、滚轮缩放

### 2. 地层建模与显示
- 三种插值算法：IDW（反距离加权）、克里金插值、RBF（径向基函数）
- 自动生成三维地层界面网格
- 半透明渲染 + 光照效果
- 支持显示/隐藏各图层

### 3. 剖面切割分析
- 自定义剖面线起点和终点
- 在 3D 场景中显示剖面线和切割面
- 辅助判断地层走向

### 4. 储量估算
- 基于钻孔数据的体积计算
- 按地层统计面积、体积、平均厚度
- 结果面板展示

## 快速体验

1. 用浏览器打开 `index.html` 文件
2. 点击左侧「加载示例数据」按钮
3. 点击「生成模型」创建三维地层
4. 体验旋转、缩放、剖面分析、储量估算等功能

## 技术栈

| 技术 | 用途 |
